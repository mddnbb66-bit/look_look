## 五、技术栈总览

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端框架** | React 18 + TypeScript | 组件化 UI 开发 |
| **构建工具** | Vite 7 | 极速 HMR |
| **状态管理** | Zustand 5 + Immer | 不可变状态更新 |
| **UI 组件** | Ant Design 6 | 企业级设计系统 |
| **样式方案** | Tailwind CSS 3 | 原子化 CSS |
| **拖拽系统** | @dnd-kit + react-rnd | 拖拽 + 缩放 |
| **图表渲染** | ECharts 6 | 可视化图表 |
| **表单引擎** | form-render | 动态表单 |
| **后端框架** | Express 4 | Node.js Web 框架 |
| **数据库** | MongoDB + Mongoose 8 | NoSQL 文档存储 |
| **AI 框架** | LangChain | Agent 编排 |
| **LLM** | DeepSeek | 大语言模型 |
| **数据校验** | Zod | 类型安全校验 |
